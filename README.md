# panchi Examples

This repo contains Jupyter notebooks demonstrating [panchi](https://github.com/Gustavo-Galvao-e-Silva/panchi) in a classroom/homework setting. Each notebook targets a distinct topic of a first linear algebra course and follows the same rhythm:

concept explanation → panchi code → step-by-step output.

---

## Notebooks

### `01_vectors_and_linear_combinations.ipynb`

**Topics:** vector arithmetic, span, linear independence, `VectorSpace`.

Introduces panchi's core `Vector` and `VectorSpace` objects. The notebook shows how simple vector arithmetic lays the groundwork for linear algebra and gives short code stubs and visualizations to display these topics.

Corresponds to: _Introduction to Linear Algebra_ (Strang) — Sections 1.2 and 2.1.
